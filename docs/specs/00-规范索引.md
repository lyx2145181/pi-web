# Pi Web 项目规范索引

## 使用说明

- 本文件登记长期项目事实的权威位置；同一事实只在一个位置完整定义，其他位置只保留摘要和链接。
- 根目录 [`AGENTS.md`](../../AGENTS.md) 继续承担开发命令、代码地图、架构不变量和高风险实现约束；[`README.md`](../../README.md) 继续承担首次使用入口。
- 新增或调整正式功能时，先确认上层能力、存在理由和范围状态，再更新对应专题规范；实施进度只写入 `docs/plans/`。
- 当前索引采用增量登记，不据此推断或重写尚未形成专题规范的既有功能契约。
