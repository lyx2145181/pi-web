# 上游 v0.9.2 更新吸收实施计划

## 计划定位

本计划用于在个人 `ui-custom` 定制基础上，分阶段吸收上游 `v0.9.2` 的底层依赖、Agent/Subagent 正确性、模型管理、会话性能和 UI 改进。本文记录实施范围、依赖顺序、冲突处理、验证门槛和回滚条件，不替代 `AGENTS.md`、ADR 或功能规格中的长期契约。

本轮目标不是把 `v0.9.2` 标签整体合并，而是：

- 保留当前精准工具、精准 Skill、Extension 生命周期保护和 Chat-only 语义。
- 保留当前会话索引、分页、缓存、项目分组、置顶排序、文件区和个人 UI 定制。
- 只吸收当前分支缺失且有明确收益的上游行为。
- 每个功能批次独立验证、独立回滚，不以整文件 `ours/theirs` 解决冲突。

功能与代码约束依据：

- [`AGENTS.md`](../../AGENTS.md)：架构、文件地图、运行时、路径安全、会话和工具策略约束。
- [`01-交互加载性能优化计划.md`](01-交互加载性能优化计划.md)：会话、文件、Git 和聊天性能的既有不变量。
- [`02-Subagent-Web交互控制台实施计划.md`](02-Subagent-Web交互控制台实施计划.md)：Subagent Web 控制台范围，不因本次上游同步扩大或替换。
- [`04-上游更新吸收实施计划.md`](04-上游更新吸收实施计划.md)：前一轮上游更新的已完成事实和冲突决策。
- [`docs/adr/0002-chat-only-tool-selection.md`](../adr/0002-chat-only-tool-selection.md)：精确工具选择与 Chat-only 契约。
- [`docs/adr/0003-built-in-subagent-toggle.md`](../adr/0003-built-in-subagent-toggle.md)：内置 Subagent 总开关契约。

## 不可退化的本地能力

### Agent、工具和 Skill

- `inclusive` / `exact` 工具策略继续由当前实现负责，不能退回只传固定工具名称。
- Chat-only 必须继续不加载不需要的 Extension、Skill、Prompt 和 Theme。
- 延迟注册工具必须继续执行启动前子集激活、启动后完整校验和 reload 校验。
- 精确 Skill 选择、空 Skill 集合、未知 Skill 拒绝和持久化字段必须保留。
- 新会话未主动选择工具时，改为遵循 Pi 的 `defaultTools`；用户主动选择的工具预设仍必须覆盖默认配置。

### Subagent

- 内置 Subagent 总开关默认关闭的既有语义不变。
- `resourceSnapshot`、profile 级工具/Skill/Extension 约束不变。
- 后台结果必须只通知一次，已通过 `get_subagent_result` 取得的结果不得再次触发父会话新一轮。
- 后台结果在压缩和上下文转换中必须被识别为 Subagent 报告，而不是用户目标。
- 内置 profile 的单独关闭只写 `agents/settings.json` 的名称列表，不复制和冻结内置 prompt。

### 会话和侧栏

- 会话索引仍是列表主数据源，不能用上游全量扫描覆盖当前索引 worker、指纹和代次机制。
- 保留项目 `projectKey` 聚合、Fork 子树、Subagent 聚合、置顶根树手动排序和折叠状态。
- 保留 60 条首屏、向前分页、消息与 `entryIds[]` 对齐、空分支和叶节点语义。
- Tab 记忆只能作为导航优先级，不能改变工作区记忆、URL 参数和已删除会话清理语义。
- 延迟详情加载不能让当前选中会话被错误卸载或重新挂载。

### 文件区和 UI

- 保留文件授权、Watcher、版本校验、Source/Preview/Diff、changed 文件入口和文件面板布局。
- 当前 `ExtensionStatusBar` 继续统一承载 Extension status/widget，不恢复独立的上下方 Widget 带。
- 当前侧栏的会话/文件纵向分割、横向宽度、拖拽平滑、键盘调整和移动端语义不能退化。
- 全局 CSS 改动必须适配现有主题变量、终端滚动条和移动端触控行为。
